# 05: 中文与含空格文件名的路径契约

**What to build:** 从 vault 搬过来的中文文件名与含空格文件名原样成立：空格转 `-`、中文不转写，生成的文件名/URL/链接三处一致，双链、嵌入、附件引用与搜索索引都指向同一个地方，浏览器里能直接打开。

**Blocked by:** 04（链接与嵌入的解析面先在）。

**Status:** ready-for-agent

- [ ] 含空格文件名产出 `带-空格-的笔记.html`，中文不被转写或拼音化
- [ ] 指向含空格/中文文件名的双链、嵌入、附件引用都能解析，URL 编码正确
- [ ] 文件树与站点索引里显示的是原文件名，不是编码后的 slug
- [ ] URL 编码往返一致：产物路径能直接复制到浏览器打开
- [ ] 已发布条目的改名不影响本条（改名靠 06 的跳转，不靠文件系统猜测）
