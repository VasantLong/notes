# 04: 链接与嵌入

**What to build:** 双链与嵌入从 Obsidian 原样搬过来就能用：`[[笔记]]`、`[[笔记|别名]]`、`[[笔记#小节]]` 各自渲染成正确的可点链接与锚点跳转，`![[笔记]]` 整篇嵌入、`![[笔记#小节]]` 只嵌那一节，`![[图片]]` 引用附件；链接按最短路径解析，所以花园库原地搬进仓不改写就有网；指向尚未发布笔记的链接被**视觉标出**，既不静默变死链也不退化成普通文本。

**Blocked by:** 03（断链标注与未发布语义共用同一套发布态判断）.

**Status:** ready-for-agent

- [ ] `[[笔记]]` 渲染为指向该条目 URL 的可点链接；URL 跟随路径，不引入 permalink 覆盖
- [ ] `[[笔记|别名]]` 显示别名而不是文件名
- [ ] `[[笔记#小节]]` 跳到该小节，目标页里锚点存在
- [ ] `![[笔记]]` 整篇嵌入；`![[笔记#小节]]` 只嵌那一节
- [ ] `![[图片]]` 引用花园库附件，且该附件出现在产物里
- [ ] 链接按最短路径解析：vault 原样搬入、不改写链接即可全部解析
- [ ] 指向未发布/不存在笔记的链接在产物里有可区分的视觉标记（断言"有标记"，不锁具体 HTML 结构）
- [ ] 嵌入页里的任务列表与表格保持可用（callout 的互动在 07 验收）
